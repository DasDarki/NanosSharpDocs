# NanosSharp Docs

Documentation of [NanosSharp](https://github.com/DasDarki/NanosSharp), built with [Docusaurus](https://docusaurus.io)
and served at https://nanossharp.dasdarki.de.

```bash
npm install
npm start        # development server
npm run build    # static site in build/
```

## Cloudflare Pages

| Setting | Value |
|---|---|
| Build command | `npm run build` |
| Build output directory | `build` |
| Environment variable | `NODE_VERSION=22` |

Add `nanossharp.dasdarki.de` as custom domain of the Pages project.
